# ZetZet AI Bot v7

## Что нового в v7

Каталог v2: **одна страница = один товар** (`/catalog/p/{id}`).

В v6 на одной странице было 50 товаров с длинными описаниями. FastBots режет
страницу на куски, и в один кусок попадали соседние товары — бот путал, какая
ссылка относится к какому товару (давал ссылку на тостер вместо чехла).

На странице товара v2:
- название, цена и ссылка — в начале и ещё раз в конце страницы;
- «Подходит для» — из параметра «Выбрать смартфон» и названия;
- полный путь категории, синонимы для поиска («айфон», «кивлар», «пауэрбанк»);
- полное описание товара из выгрузки сайта.

Данные перечитываются из YML-выгрузки фоновым потоком каждые `REFRESH_HOURS`
часов (по умолчанию 4). `/update` по-прежнему обновляет сразу.

Старые адреса `/fastbots/` и `/sitemap.xml` оставлены без изменений.

## Адреса

| Адрес | Что это |
|---|---|
| `/catalog/sitemap.xml` | sitemap страниц товаров v2 — **его добавлять в FastBots** |
| `/catalog/p/{id}` | страница одного товара |
| `/catalog/` | служебный список ссылок (не обучать на нём бота) |
| `/update` | принудительно перечитать выгрузку |
| `/fastbots/`, `/sitemap.xml` | старый формат v6 |

## Переключение FastBots на v2

1. Дождаться деплоя на Railway, открыть `/update`, проверить `/catalog/p/1834057`.
2. FastBots → Links / Docs → Add Links → Sitemap:
   `https://fastyfastybots-production.up.railway.app/catalog/sitemap.xml`
3. Дождаться, пока все страницы станут Indexed.
4. Удалить из Links / Docs старые 37 страниц «Каталог ZetZet — страница N» и «База товаров ZetZet.ru».
5. Включить Scheduled Retrain → Daily для новых страниц.

## Переменные окружения

- `FEED_URL` — адрес YML-выгрузки.
- `REFRESH_HOURS` — как часто перечитывать выгрузку, часов (по умолчанию 4, 0 — выключить).
